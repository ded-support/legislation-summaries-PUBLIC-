Summary

LB441 amends section 71-6401 (Building Construction Act) to authorize state agencies, counties, cities, or villages that require building inspections to allow virtual inspections under specified conditions. "Authorized inspector" is defined as an individual credentialed with the issuing state agency, county, city, or village, or a third‑party inspector registered/licensed with the State of Nebraska and contracted per project specifications. Virtual inspections are permitted for residential buildings under three stories and under 10,000 sq ft, require a provided list of onsite personnel, and must be live except that nonstructural reinspections may use video/photo documentation. Inspection records must be made available to the public if the structure is standing when requested. No appropriations or funding changes are included.

Underlined (Added) Text Summary

Defines "authorized inspector" as a person credentialed by the state agency, county, city, or village issuing permits, or a third‑party inspector registered/licensed with the State of Nebraska (excluding self‑inspections). Defines "inspection records" as pass/fail results and reasons tied to the permit address.

Requires any state agency, county, city, or village that mandates inspections for building permits to:

- permit live virtual inspections for residential buildings under three stories and 10,000 sq ft if the permit holder provides an onsite personnel list and both parties participate live;

- allow video/photo documentation for reinspections of nonstructural work when the permitting entity so determines;

- use an authorized inspector for building or structural inspections.

Inspection records must be made public if the structure is still standing when requested. No funding or appropriation changes are included.
