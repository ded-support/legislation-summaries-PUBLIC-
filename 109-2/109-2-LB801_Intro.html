Summary

LB801 updates Nebraska’s state building code (amending §71-6403) and local adoption rules (§71-6406). It adopts by reference specified components of current model codes, notably chapter 13 of the 2024 International Building Code and chapter 11 of the 2024 International Residential Code, along with portions of the 2018 IBC, the 2018 International Existing Building Code (except §809), and the 2018 Uniform Plumbing Code. The bill maintains the two‑year local adoption window after state code updates (otherwise the state code applies, excluding farm construction) and clarifies conformity criteria for local codes. It requires counties, cities, and villages to notify the Department of Water, Energy, and Environment within 30 days if they delete chapter 13 (2024 IBC) or chapter 11 (2024 IRC). No funding or appropriation changes are included.
