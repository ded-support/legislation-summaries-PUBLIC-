Summary

LB801 updates Nebraska's state building code and clarifies local code conformity. Key governmental actors and duties:

- Department of Water, Energy, and Environment: must receive notice within 30 days if a county, city, or village amends its local code to delete any portion of chapter 13 (2024 IBC) or chapter 11 (2024 IRC).

- Counties, cities, and villages: must adopt the state building code or a code that "conforms generally"; if they fail to adopt within two years after a state update, the state code applies (excludes farm construction). Local governments must regularly update codes (within two years of state updates) and may adopt administrative amendments; public buildings must follow applicable local/state codes. Fees for intergovernmental monitoring of code application are negotiable and limited to actual expenses.

No changes to funding, appropriations, or budget allocations are included. Original sections 71-6403 and 71-6406 are repealed and replaced.
